# Değişiklikler

## 0.2.0-dev.3

- Terminalde sağlayıcı ve arama için numaralı seçim menüleri.
- Sağlayıcıdan model listesi alıp seçim yapma; listeleme hatasında açık durdurma.
- Kurulum sonunda tamamlanma özeti ve sonraki komutlar.
- `ragents uninstall`: uygulama, PATH, seçili profilin hizmeti ve bu kuruluma
  ait yerel MCP kayıtlarının kaldırılması; kullanıcı verilerinin korunması.
- Özel ayar yoluyla eklenen yeni MCP kayıtları için kaldırma envanteri.
- Kişisel geliştirme yollarından arındırılmış MCP örnekleri.
- Ürün odaklı README ve ayrı geliştirici rehberi.
- Python 3.12/3.13 annotation ve yeni MinGit dizin düzeni uyumluluk düzeltmeleri.

Geliştirme ön sürümüdür. Gerçek hesaplarla model/arama/istemci kabulü ve
20 senaryonun üç tekrarı tamamlanmamıştır. Ek ücretli model testi yapılmaz.
Kod imzası yoktur.
